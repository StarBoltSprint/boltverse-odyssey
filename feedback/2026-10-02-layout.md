Exit 1. After the fix the same run prints `l1 round outside=0` and `PASS yaw_band checked=67 outside=0`, and `l1 organic outside=0` and `PASS yaw_band checked=1072 outside=0`. A runtime interior at 120° fails the row: organic `worst_id=hero-00 worst_offset_deg=120.0000 worst_excess_deg=105.0000`; round `worst_id=mid-00 worst_offset_deg=120.0000`. Organic variety stays `identical_neighbours=0, spread=0` and adds `yaw_span_deg=22.9890, yaw_span_cat=exit`. Round-mode samples with the key absent keep their bytes. No threshold constant changed. - Reproduce: On 1af0856, `python3 tools/layout/selftest.py`. The organic-good spec sets `yaw_band_deg` on boundary, exit, mid, near, hero, and scatter-fore / scatter-mid / scatter-far. The round case sets the same keys in memory on the circle spec. Stdout ends with the FAIL line above. Exit 1.
- Still / screenshot: tools/layout/sample/organic-good/debug-topdown.png
- Short video:
- Proposed fix: Per-category `yaw_band_deg` and `yaw_ref` (`world` = yaw 0, `inward` = heading_deg + 180). `generate` applies the band after placement in circle mode and organic mode. `variety` measures spread inside the band and does not penalise a band that cannot express an offset difference larger than `yaw_eps_deg`. `check` adds row `yaw_band` and prints the worst offender. Placed labels `boundary-N` use the `boundary` band. When the spec omits the key, yaw, the clearing, and the report stay as they are.
