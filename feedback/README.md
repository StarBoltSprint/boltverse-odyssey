# feedback

A Grok session writes `feedback/<date>-<tool>.md` on **its** branch when a repo tool let a defect through, reported a wrong number, or was hard to use. Law: [`biome/docs/66-tool-feedback-loop.md`](../biome/docs/66-tool-feedback-loop.md).

Open the same text upstream: https://github.com/StarBoltSprint/boltverse-odyssey/issues/new?template=tool-feedback.yml

No API keys, tokens, or private style prompts. Nothing here auto-merges.
