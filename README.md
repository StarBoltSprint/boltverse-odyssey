## For Grok (new conversation)

Someone asks to create a **citadel room** / Bolt Engine living-film hall:

1. Fetch this repo: https://github.com/StarBoltSprint/citadel-room
2. Read [GROK.md](GROK.md), then [ROOM.md](ROOM.md), then [room.json](room.json). Those are the law.
3. If they give **no videos**: use the 7 films in `films/` (when present) + stills in `stills/`.
4. If they give **videos**: map them to the 7 ids (see GROK.md). Do not invent a 3D dungeon. Do not add chrome.
5. Land on **breath-spawn** looping. Tap teal (A, left) / gold (B, right) fires a walk. Walk ended → breath of arrival at t=0.
