# Jade plate prompts

Law [48](../../docs/48-jade-plate-cook.md). The room, not the furniture. Sheets stay cutouts ([SHEETS.md](SHEETS.md)). No binaries in this folder.

Hang this shared block on the ground cook and on the sky cook.

```
late-day, gold key upper-left, cyan fill, same hour as the bole sheets,
loop 6 to 10 seconds, first frame matches last, muted,
no camera truck, no dolly, no yaw inside the clip, the pawn owns travel,
no near bole, no readable tree, no ruin, no crystal, no fern,
no path tiles, no Bolt, no dog, no wolf, no German Shepherd,
no horizon props in card space, no baked tree shadows that will also spawn
```

## Ground

Square floor, 1920² or 2048². Not 9:16.

```
dirt you stand on, moss grain, fine roots, wet sheen, tiny décor stones,
light crawl, mist texture, flatter moss color for a path tone,
not a modeled road, not curbs, no valley cut into the dirt
```

Then the shared block.

## Sky

Lat-long, 2048×1024. The lower 10% cousins the ground's outer edge.

```
sky lid, canopy-filtered late-day, distant haze,
two or three unreadable far blobs, gold rim, cyan vault,
no landable cliff, no countable branches
```

Then the shared block.

Posters are the first frame of each clip. The engine shows the poster until decode. Optional `jade_ground_still.jpg` uses the same UV when the video is late.
