# 01 — images (stills)

Two still kinds. Never mix them into one photo.

## Empty plate (road)

Photoreal **9:16** `720×1280`. Locked-off camera. **ZERO** dogs. **ZERO** German Shepherds. **ZERO** animals. **ZERO** people. **ZERO** luminous floor paths. **ZERO** Y-fork. **ZERO** citadel portals. **ZERO** HUD / text.

CLEAR empty center corridor (the cutout plants there). Subtle rails / curbs OK. Canyon / Mars / named `{PAINT}` décor OK.

Still only — this is `image` / `last_frame` for the road film, not a hall spawn.

Paste: [../prompts/image-empty-plate.txt](../prompts/image-empty-plate.txt). Swap `{PAINT}` only.

Plate N+1 still = extracted last frame of road N, then a **new** end still (world advanced). Do not cut to a fresh establishing shot.

## Hazard still (cousin)

Same lock as the empty plate. Bake **one** obstacle into the pixels (wet contact).

**THREE lanes. Hazard = 1 or 2 lanes. NEVER all three.** Always one free dodge corridor. A full-width bar is FAIL (unavoidable).

Paste: [../prompts/image-hazard-plate.txt](../prompts/image-hazard-plate.txt).

## Bolt mid (cutout)

ONE full-white German Shepherd. White coat forever. Teal collar. **BACK** to camera (crown / withers; muzzle hidden). Lower third. Four paws. Standing or already in a gallop plant — **never sit, never face, never 3/4**.

Background: **soft black** (keyable). No second dog. No hall portals. No HUD.

Paste: [../prompts/image-bolt-mid.txt](../prompts/image-bolt-mid.txt).

Identity teacher for the coat: [../../lock/bolt-back.jpg](../../lock/bolt-back.jpg) — coat only, not hall scale.

## Banned

- Dog in the empty plate
- Grey / silver / black **as the coat base** (skin ON TOP of white OK)
- Face / muzzle / sit on the cutout still
- Chrome UI rectangles, TAP stamps, path lightning
- Full-width hazard on all three lanes
