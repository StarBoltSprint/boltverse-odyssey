# objsheet samples

Generated by `python3 tools/objsheet/selftest.py`. Each folder has `sheet.png`, `report.json`, and `report.md`.

The sheets are proofs. The cyan line is the measured mask. Do not hang a sheet and do not sample it as a texture.

`repo-synthetic-rock`, `guides-good`, and `with-spur` pass. `bad-guide` and `inconsistent` fail on purpose. `real-void-orbit` is eight real stills from `biome/void-orbit/stills/`; adjacent area and height fail the silhouette lock. Those stills were not cooked as one 8-view object.
